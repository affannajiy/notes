## In one sentence

An operating system's core job is arbitration, deciding which program gets access to a computer's limited memory, processing time and hardware at any given moment, and the reason most people never think about this constant negotiation happening underneath every click is precisely because a well designed operating system makes that arbitration invisible.

## What it is

An operating system is the software layer sitting between a computer's physical hardware and the applications a user actually runs, managing memory allocation, process scheduling, file storage and hardware communication so that individual applications do not need to handle those low-level details themselves.

## Types

Desktop and laptop computers run general-purpose operating systems, Windows, macOS and Linux distributions being the dominant examples, each built to support a broad range of applications and hardware configurations. Mobile operating systems, iOS and Android, are built around different priorities, battery efficiency and app sandboxing, isolating each app from others for security, mattering more than the broad hardware flexibility a desktop system needs. Embedded operating systems, running inside devices like cars, appliances and industrial equipment, are typically stripped down to the minimum functionality a specific device actually needs, prioritising reliability and low resource use over general flexibility.

## Terms

A few terms recur across operating system discussion worth defining plainly. A "kernel," the operating system's core component, directly manages hardware access, memory and process scheduling, with everything else in the operating system built as a layer on top of it. "Open source," describing software whose underlying code is publicly available for anyone to inspect, modify and redistribute, is the model behind Linux, contrasting with the closed, proprietary source code Windows and macOS keep private.

## History in moments

Early computers in the 1950s and 1960s ran without a true operating system at all, executing one program at a time with no automatic management of shared resources. Unix, developed at Bell Labs beginning in 1969, established many of the fundamental concepts, multi-user support, hierarchical file systems, still underlying most modern operating systems, including the Linux and macOS lineages that trace their design philosophy directly back to it. The rise of graphical user interfaces through the 1980s, popularised by Apple's Macintosh and later Microsoft Windows, shifted operating systems from text-command interfaces toward the visual, mouse-driven interaction model still dominant on desktop computers today.

## Malaysian connection

Malaysia's government has periodically promoted open-source software adoption in public sector computing, partly to reduce licensing costs and partly to build domestic technical capability, though proprietary systems like Windows remain dominant across most Malaysian businesses and households in practice.

## What's happening now

Operating systems are increasingly designed around cross-device continuity, letting a user start a task on one device and continue seamlessly on another, a priority covered from the Apple ecosystem side of this vault, reflecting a broader industry shift where the operating system's boundaries matter less than the overall experience spanning several connected devices at once.
